# HospitalUnicaes-Api

Backend unificado (Node.js + TypeScript + Express + Prisma) del sistema de gestión del Hospital Universitario Central.

Parte del proyecto HospitalUnicaes (Desarrollo de Aplicaciones Móviles Avanzadas, UNICAES).

El proyecto base se agrega en la rama `development`. Ver `CONTRIBUTING.md` para el flujo de ramas.
